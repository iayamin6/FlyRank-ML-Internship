- **Notebook 01:** client-holdout Precision@50 is **0.240** for the reference weighted baseline and **0.680** for the random forest: 12 versus 34 declining pages out of 50, or 2.83× lift. This measures ranking precision, not accuracy.
- **Discovery exercise:** restricting to positive impressions removes zero rows. Pearson correlation between keyword search volume and impressions is **0.001203** in both populations, using **27,532** complete pairs; **2,468** missing keyword estimates are excluded rather than zero-filled. This is a weak observed linear association within a selected sample, not proof of no relationship.
- **Notebook 02:** the in-sample hand rule/tree Precision@20 is **0.900/0.800**, and Precision@50 is **0.620/0.720**. The deliberately leaky tree scores **1.000**, illustrating why label-derived features are invalid.
- **Independent holdout experiment:** the reference seed-42 split separates **26/6 clients** and **27,675/2,325 pages**, with zero client overlap. Depths 2/3/4 have stable Precision@50 **0.520/0.620/0.580** and random-tie expectations **0.5142/0.5600/0.5367**. All hand-rule scores are zero on the holdout; its expected precision is simply the **0.3910** decline prevalence. Depth 3 has eight readable leaves and average precision **0.5329**.

The hand rule in Notebook 02 is different from Notebook 01's weighted reference baseline. Shallow-tree top-K rankings have large ties. These exploratory comparisons are not an untouched final-test estimate. Snapshot feature windows overlap the decline window, so the results concern observed decline on held-out clients, not future forecasting or causal refresh benefits. The reference pipeline selects its winning model on the same holdout; its exported full-data queue is not an out-of-sample evaluation.

## Reproduce

From the repository root, create a Python 3.13 environment and install `work/assignment01_requirements.txt` (the tested direct dependency versions). Then run both notebooks from top to bottom in Jupyter, or execute them programmatically:

```python
from pathlib import Path
import nbformat
from nbclient import NotebookClient

for path in sorted(Path("notebooks").glob("0[12]*.ipynb")):
    notebook = nbformat.read(path, as_version=4)
    NotebookClient(notebook, timeout=900, kernel_name="python3",
                   resources={"metadata": {"path": str(Path.cwd())}}).execute()
    nbformat.write(notebook, path)
```

Activate the installed environment before running this code. Both notebooks also retain their Colab setup, pointed at this repository. The original broad requirements remain unchanged; other library versions can change top-K tie ordering and model results.
